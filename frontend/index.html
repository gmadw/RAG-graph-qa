模型设置

默认预设均为免费渠道；也支持本地 Ollama 与任意 OpenAI 兼容 API

对话模型（LLM）

用于回答生成与知识图谱抽取。只用硅基流动一把 Key 即可：默认 GLM-4-9B-0414（最快最省），也可选 DeepSeek-R1-0528-Qwen3-8B / Qwen3-8B（推理模型，更慢但复杂问题更强）；本地 Ollama 亦可

向量模型（Embedding）

文档与查询向量化。免费推荐：硅基流动 BAAI/bge-m3 / 本地 Ollama bge-m3

重排序模型（Rerank，可选）

对检索结果精排，可提升准确率。硅基流动 BAAI/bge-reranker-v2-m3 免费。不启用则跳过

文档 OCR（扫描件 / 图片识别）

扫描件 PDF 与图片没有文字层，需要用视觉模型识别文字。云端可用硅基流动的 PaddleOCR-VL-1.5、DeepSeek-OCR；本地 Ollama 推荐 glm-ocr（智谱 0.9B，识别精度最好）或 richardyoung/unlimited-ocr（百度 3.3B，长文档）。关闭时扫描件会明确提示无法提取文字

检索与图谱参数

知识图谱本体（Ontology）

自定义实体与关系类型，约束 LLM 抽取口径，让图谱更贴合你的领域（对齐 cognee 的 ontology 能力）。留空则使用内置通用类型。
修改本体后，对已有文档点「建图谱」可全量重建以应用新类型。
